# SoundCloud Compact для Windows

Скрипты для локальной модификации интерфейса SoundCloud: масштаб примерно **80%**, постоянно открытая громкость в плеере и вертикальная полоска в боковой панели.

[Основной README](../README.md) · [Технические заметки](TECHNICAL.md) · [Проверки и замеры](VALIDATION.md)

## Что опубликовано

Собственные Python/PowerShell-скрипты, документация и проверки. Файлов SoundCloud, его DLL, bundle, обложек, данных аккаунта и готового модифицированного приложения в репозитории нет.

Поддерживается только **SoundCloud 2.12.4.0 x64**, Hermes **HBC96**, с точным хешем исходного bundle. Другие обновления скрипт отклоняет. Уже установленный оригинал не изменяется.

## Установка

Нужны Windows, Python 3.12, Git и установленная поддерживаемая версия SoundCloud. Для регистрации отдельной локальной копии включите режим разработчика в параметрах Windows. Скрипты сами системные политики не меняют.

В PowerShell, из папки проекта:

```powershell
.\Setup-Tools.ps1
.\Copy-InstalledPackage.ps1
python tools/prepare_compact.py
.\Register-Compact.ps1
```

Приложение называется **SoundCloud Compact 80 (local)**. Войдите в него через экран активации. Для последующих запусков:

```powershell
.\Launch-Compact.ps1
```

Этот скрипт устанавливает приоритет BelowNormal только процессу локальной копии и завершается. При запуске через меню Пуск пониженный приоритет заново не выставляется.

Не переносите папку зарегистрированной копии и не запускайте скопированный exe напрямую. Перед повторной сборкой закройте локальное приложение. Ошибка регистрации `0x80073CFF` означает, что Windows не разрешает развёртывание приложений разработки.

## Что изменено

- Общий эталон размеров 940 × 540 заменён на 1175 × 675. Значения, проходящие через SizeUtil, становятся примерно 80% прежних.
- Горизонтальная громкость в плеере открыта без наведения.
- Вертикальная громкость в боковой панели использует тот же компонент и состояние.
- Убраны анимации появления полоски и декоративного эквалайзера.
- Отключена инициализация Sentry.
- Стандартное хранение неактивных query-данных сокращено с 300 до 60 секунд. При возврате на закрытый экран данные могут загружаться заново.

## Нагрузка

В коротком замере воспроизведения со свёрнутым окном: **около 0,33% общего CPU** на 8 логических процессорах, **199,2 МиБ рабочего набора**, **251,7 МиБ private commit**.

Существенное уменьшение RAM не доказано. Постоянная полоска также добавляет некоторую нагрузку при открытом окне. Для игры лучше свернуть приложение. Это не обещание конкретного FPS: Valorant и влияние на FPS не тестировались.

## Откат

Вернуть вариант только с масштабом 80%, сохранив локальную регистрацию и данные аккаунта:

```powershell
# Сначала закройте локальное приложение.
python tools/prepare_compact.py --baseline
.\Launch-Compact.ps1
```

Полностью удалить отдельную локальную регистрацию и её данные:

```powershell
.\Rollback-Compact.ps1
```

Оригинальный Store-пакет остаётся установленным.

## Проверки и авторство

`python -m unittest discover -s tests -v` проверяет защиту от неподдерживаемых входных файлов. При наличии локального исходного bundle дополнительно проверяются точные хеши результата и контрольная сумма Hermes.

На рабочем приложении проверены оба регулятора, их синхронизация, переходы между экранами и воспроизведение. Изменённый bundle повторно дизассемблирован.

Проект разработан с помощью **OpenAI Codex**. Для разбора bytecode используется **hermes-dec**; версия закреплена в Setup-Tools.ps1. Лицензия собственных скриптов и документации — AGPL-3.0-or-later. Лицензия не распространяется на стороннее приложение SoundCloud.
